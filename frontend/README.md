# React + TypeScript + Vite

Ce template fournit une configuration minimale pour faire fonctionner React dans Vite avec le HMR et quelques regles ESLint.

Actuellement, deux plugins officiels sont disponibles :

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) utilise [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) utilise [SWC](https://swc.rs/)

## React Compiler

Le React Compiler n'est pas active sur ce template a cause de son impact sur les performances de dev & build. Pour l'ajouter, voir [cette documentation](https://react.dev/learn/react-compiler/installation).
